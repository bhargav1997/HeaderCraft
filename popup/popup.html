    URL Filter & Regex Patterns

    Use these patterns in the URL Filter field for headers, redirects, and query param rules.

    PatternMatches
    https://api.example.com/v1Exact prefix match
    *api.staging.com*Any URL containing api.staging.com
    ||example.comAny scheme/subdomain on example.com
    ^https://api\\.dev\\.com/users/\\d+$Regex: user ID endpoint (enable "Regex" toggle)
    *?utm_*Any URL with UTM query parameters

    Core Tips

    • Mock API rules intercept fetch() and XMLHttpRequest only. They do not intercept top-level page navigations or <script> tag loads.
    • Bypass CORS: Add a Response header rule setting Access-Control-Allow-Origin to *. Use the "Bypass CORS" preset for 1-click setup.
    • Tab Scoping: Click "All Tabs" next to the ON switch to restrict rules to the current tab only. Other tabs remain unaffected.
    • Auto-Disable Timer: Set a countdown (15m to 8h) to automatically turn off the active profile, preventing accidental token leaks.
    • Hit Counters: Green pulse dots on rule cards track live request matches during the current session.
