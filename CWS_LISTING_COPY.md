## 📝 3. Detailed Description (Copy & Paste Into CWS Dashboard)

HeaderCraft is a 100% free, local-first developer tool built for modern web engineering. Effortlessly modify HTTP request and response headers, redirect URLs to localhost, manipulate query parameters, and mock API responses in real-time—directly inside Chrome with zero external backend or cloud servers.

Designed from the ground up on Chrome’s secure Manifest V3 engine (`declarativeNetRequest`), HeaderCraft provides a powerful, high-performance toolkit for developers, DevOps, and QA engineers without subscription paywalls, data collection, or telemetry.

**🛡️ Why Choose HeaderCraft?**

* **100% Local & Private:** Your headers, API tokens, and mock data never leave your browser. Zero tracking, zero telemetry, zero external servers.
* **Truly Free & Unlimited:** Unlimited profiles, rules, and mocks. No account required, no subscription tiers, no paywalls.
* **Seamless Migration:** Built-in JSON importer allows you to migrate your existing profiles from legacy tools like ModHeader or Requestly in seconds.
* **Manifest V3 Native Engine:** Built on Chrome's ultra-fast `declarativeNetRequest` API for instantaneous execution without slowing down your browser.
* **Isolated Tab Scoping:** Restrict rules to a single browser tab without affecting your other open tabs or personal browsing sessions.

**🚀 Core Features Breakdown**

**1. Custom HTTP Request & Response Headers**

* Modify headers on the fly: Set, Append, or Remove any request or response header.
* Bypass CORS instantly (`Access-Control-Allow-Origin: *`, `Access-Control-Allow-Methods`).
* Inject `Authorization: Bearer <token>` or custom headers for staging and production testing.
* Inject Dynamic Variables: Use `{{$uuid}}`, `{{$timestamp}}`, and `{{$randomInt}}` to generate fresh data on every request.
* Live Hit Counters: View real-time match counters on rule cards during active sessions.

**2. URL Redirects & Dev Server Rewriting**

* Map production or staging URLs directly to your local development server (e.g., redirect `https://myapp.com/bundle.js` to `http://localhost:3000`).
* Supports resource-type filtering, Exact, Prefix, and RegEx matching.

**3. Query Parameter Rules**

* Automatically append, modify, or strip URL parameters (e.g., force `?debug=true` or remove `utm_source`).

**4. Client-Side API Mock Interceptor**

* Intercept `window.fetch` and `XMLHttpRequest` network requests locally without needing a backend server.
* Return custom HTTP status codes (200, 400, 401, 404, 500) and mock JSON payloads to test frontend error handling.

**🔐 Permissions & Privacy Transparency**

HeaderCraft requires only minimal permissions strictly necessary for network rule execution:

* `declarativeNetRequest`: Used natively to modify HTTP headers and perform URL redirects locally.
* `storage`: Used to persist your custom profiles locally in your browser.
* `alarms`: Used for background alarms and dynamic variable updates.

HeaderCraft does not collect, store, transmit, or analyze any user data, browsing history, or network traffic.
