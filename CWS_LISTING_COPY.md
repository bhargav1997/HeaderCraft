## 📝 3. Detailed Description (Copy & Paste Into CWS Dashboard)

HeaderCraft is a 100% free, local-first developer tool built for modern web engineering. Effortlessly modify HTTP request and response headers, redirect URLs to localhost, manipulate query parameters, and mock API responses in real-time—directly inside Chrome with zero external backend or cloud servers.

Designed from the ground up on Chrome’s secure Manifest V3 engine (`declarativeNetRequest`), HeaderCraft provides a powerful, high-performance toolkit for developers, DevOps, and QA engineers without subscription paywalls, data collection, or telemetry.

**🛡️ Why Choose HeaderCraft?**

* **100% Local & Private:** Your headers, API tokens, and mock data never leave your browser. Zero tracking, zero telemetry, zero external servers.
* **Truly Free & Unlimited:** Unlimited profiles, rules, and mocks. No account required, no subscription tiers, no paywalls.
* **Workspaces & Folders Organization:** Organize test suites like Postman and Requestly with multi-workspace isolation and collapsible folders.
* **Cookie Vault (Session Cookie Store):** A per-domain cookie store that persists across requests, ensuring authenticated session flows behave exactly as they do in a real browser.
* **Universal Migration & Import Hub:** Bring collections, environments, and test variables across from **Postman**, **Insomnia**, **Bruno**, **OpenAPI / Swagger**, **HAR**, **cURL**, **SoapUI / WSDL**, **ModHeader**, and **Requestly** without rewriting test scripts.
* **Manifest V3 Native Engine:** Built on Chrome's ultra-fast `declarativeNetRequest` API for instantaneous execution without slowing down your browser.
* **Isolated Tab Scoping:** Restrict rules to a single browser tab without affecting your other open tabs or personal browsing sessions.

**🚀 Core Features Breakdown**

**1. Cookie Vault (Per-Domain Session Cookie Store)**

* **Persistent Session Flows:** Maintain authenticated sessions across API calls and page reloads by persisting cookies per domain.
* **One-Click Live Cookie Import:** Fetch live session cookies directly from your active browser tab.
* **Browser Cookie Synchronization:** Sync stored cookies into Chrome's native cookie store or inject them dynamically via `Cookie` request headers.
* **Cookie String Parser:** Paste raw cookie strings (`key1=val1; key2=val2`) or cURL `--cookie` commands to populate domains in seconds.

**2. Universal Migration & Import Hub (Postman, Insomnia, Bruno, OpenAPI, HAR, SoapUI)**

* **Postman Collections & Environments (v2.0 / v2.1):** Automatic extraction of headers, bearer/basic auth tokens, query parameters, custom variables, and mock responses.
* **Insomnia v4/v5 Workspaces:** Import requests, auth headers, environments, and Insomnia Cookie Jars.
* **Bruno Collections & .bru Files:** Direct import of Bruno plaintext `.bru` files and collection JSONs.
* **OpenAPI 3.x & Swagger 2.0:** Auto-extract endpoints, headers, query parameters, and mock responses from JSON/YAML specifications.
* **HAR (HTTP Archive) Network Captures:** Import Chrome DevTools Network captures to reconstruct request headers, cookies, and responses as Mocks.
* **SoapUI & WSDL Projects:** Parse SOAP XML definitions, endpoints, and `SOAPAction` headers.
* **cURL Commands & URLs:** Instantly convert copied `curl` terminal commands or API URLs into active testing profiles.

**3. Workspaces & Collapsible Folders (Postman & Requestly Style)**

* **Multi-Workspace Isolation:** Create isolated workspaces (e.g. `Personal`, `Staging QA`, `Client Projects`) with dedicated profiles and settings.
* **Collapsible Folders:** Group and structure related profiles inside custom folders (e.g., `📁 Auth Headers`, `📁 Payment APIs`, `📁 Mock Endpoints`) with one-click expand/collapse.
* **Profile Folder Picker:** Easily move and categorize any testing profile between folders.

**4. Custom HTTP Request & Response Headers**

* Modify headers on the fly: Set, Append, or Remove any request or response header.
* Bypass CORS instantly (`Access-Control-Allow-Origin: *`, `Access-Control-Allow-Methods`).
* Inject `Authorization: Bearer <token>` or custom headers for staging and production testing.
* Inject Dynamic & Custom Variables: Use built-in dynamic tokens (`{{$uuid}}`, `{{$timestamp}}`, `{{$isodate}}`, `{{$date}}`, `{{$randomInt}}`) or define custom key-value variables (`{{api_key}}`, `{{env}}`) to substitute values across headers, redirects, and query parameters.
* Expand to Full Tab: One-click pop-out to a full responsive browser tab with optimized spacious viewports for multi-monitor developer workflows.
* In-App Syntax & Help Reference: Interactive guide with one-click copy buttons for variables and regex patterns.
* Live Hit Counters: View real-time match counters on rule cards during active sessions.

**5. URL Redirects & Dev Server Rewriting**

* Map production or staging URLs directly to your local development server (e.g., redirect `https://myapp.com/bundle.js` to `http://localhost:3000`).
* Supports resource-type filtering, Exact, Prefix, and RegEx matching.

**6. Query Parameter Rules**

* Automatically append, modify, or strip URL parameters (e.g., force `?debug=true` or remove `utm_source`).

**7. Client-Side API Mock Interceptor**

* Intercept `window.fetch` and `XMLHttpRequest` network requests locally without needing a backend server.
* Return custom HTTP status codes (200, 400, 401, 404, 500) and mock JSON payloads to test frontend error handling.

**🔐 Permissions & Privacy Transparency**

HeaderCraft requires only minimal permissions strictly necessary for network rule execution:

* `declarativeNetRequest`: Used natively to modify HTTP headers and perform URL redirects locally.
* `storage`: Used to persist your custom profiles, workspaces, folders, rules, and Cookie Vault locally in your browser.
* `cookies`: Used strictly by the Cookie Vault to inspect, save, and restore local session testing cookies for user-specified domains.
* `alarms`: Used for background alarms, auto-disable profile timers, and dynamic variable updates.

HeaderCraft does not collect, store, transmit, or analyze any user data, browsing history, or network traffic.
